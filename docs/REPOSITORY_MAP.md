# Published source map

The initial source commit included the core authored baseline controllers, state adapters, selected OS/COSMIC build and boot recipes, source/component checks, live symbolic-context preparation, MetaMo v3, the NARS subset bridge, and MORK hardening. The publication manifest records that initial subset; it is not a complete inventory of later additions. Superseded entries are removed when their files are retired.

The separately prepared showcase avatar, additional baseline test/recipe files, symbolic-ai-v4 and symbolic-granite-v7 sources are not all present in this first public subset. Their prior observed status is described separately from included file coverage. Experimental unprivileged operational sources and host/runtime inventories remain omitted. No complete runtime or image is promised.

## AI learning development additions

- `metamo-core-v4`: corrected bounded MAGUS source, retained prior host result and portable tests. See `PORTABLE_NOTES.md`.
- `metamo-controller-adapter-v2`: typed immutable evidence/proposal adapter, 53 pure tests, separate native qualification pending.
- `components/nace`: MIT-licensed seven-function predictive/evidence slice with authored typed adapter and reference tests. Native qualification pending.

These additions do not amend the historical first-publication allowlist. They contain no runtime inventories, raw captures or private proof files.

- `components/airis`: authored bounded scalar transition learning experiment, observed prior host result and portable tests. Original AIRIS source/runtime remain external.

## MetaMo cleanup

`metamo-core-v3` was retired after its corrected successor, `metamo-core-v4`,
landed. The old source remains in Git history at commit
`d8674e20ffa48798abc09dacc111ccaf30d7221d` (the parent of this cleanup).
The v3 native attempt failed; its source is not a second supported runtime.

Keep `metamo-core-v4`: the controller adapter and Omega conversation hook
resolve its numeric compatibility module and external upstream layout. It also
contains the corrected import order, upstream consumer probe, gateway
finalization fixes, source lock, original MIT license, and historical native
result. Removing it would break these consumers. No v4 source or frozen
qualification data was changed by this cleanup, and no new native run is claimed.
