# Published source map

This initial source commit includes the core authored baseline controllers, state adapters, selected OS/COSMIC build and boot recipes, source/component checks, live symbolic-context preparation, MetaMo v3, the NARS subset bridge, and MORK hardening. The publication manifest is the exact authoritative file list.

The separately prepared showcase avatar, additional baseline test/recipe files, symbolic-ai-v4 and symbolic-granite-v7 sources are not all present in this first public subset. Their prior observed status is described separately from included file coverage. Experimental unprivileged operational sources and host/runtime inventories remain omitted. No complete runtime or image is promised.
