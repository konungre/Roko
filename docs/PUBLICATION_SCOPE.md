# Initial publication scope

The source tree is a separate allowlisted copy. Original workspace files,
checkpoints and artifacts were not overwritten or deleted.

Included: authored controller/state/CLI/package-manager source, bounded AI
adapters and tests, selected OS and native-build recipes, delivered showcase
and avatar source, and clearly labeled experimental diagnostics/integrations.

Excluded: vendor runtime/source dumps, private ECAN and unlicensed MORK/FFI
source, model weights, binaries/shared libraries, archives and disk/VM images,
private state, screenshots/runtime capture logs, credentials, internal notes,
private artifact identities, upstream artwork/background pixels, and unfinished
native-context successor qualification. Very large file inventories are omitted.

Three source/document or binding files contain public placeholder
redactions where private artifact identities were embedded. The publication
manifest records which files changed. Those placeholders are not usable runtime
authorization and must not be bypassed.

High-confidence credential patterns and private artifact identifiers were scanned
before publication, alongside the allowlisted source review. This is not a proof
that every possible secret pattern can be detected.

No project-wide open-source license has been selected for newly authored code.
Public visibility does not itself grant broader reuse rights. Included upstream
license/notice text retains its existing terms. No relicensing is intended.

## Additional metadata exclusion

Detailed development runtime path/hash inventories and old artifact locks were removed before final publication. Original development documentation was replaced with concise public scope summaries. Source development-root literals use a generic public placeholder where necessary; real native admission is intentionally unavailable without fresh reviewed provisioning.
