# Durable native conversation integration

This successor joins the durable v2 endpoint with the cognitive checkpoint
`f07e16d` and the separately supplied MORK checkpoint. The original `55bebd8`
and `0493700` checkouts and profiles remain recovery points. The configured main
checkout is not changed by this feature branch.

The public request/response contract remains [DURABLE_API.md](DURABLE_API.md).
Launch `durable_server.py` for API v2; `fresh_server.py` remains the v1 endpoint.
The basilisk client must explicitly adopt v2 before switching launchers.

partial-output replay, input rejection, resident-model cancellation and explicit

These are this host's measured cases, not a latency guarantee. All 114 conversation

## Execution and durability

A committed CAS claim precedes native MORK retrieval, ECAN attention selection,
optional NAL-1 inference, and Omega/PeTTa dispatch to local Granite. SQLite owns
history and revisions. Successful conversation history, the derived-observation
ledger, and the response commit in one transaction before delivery. Saved replay
runs none of those native components again. Cancellation never auto-retries;
explicit recovery requires the prior owner to be dead.

MORK indexes generated turn IDs and roles. Every expected native row must return
before the adapter hydrates the original transcript text, in order. It does not
index raw user text as executable expressions. It uses a separate SWI 9.3.34
process, not the Janus-loaded symbolic process. Its PathMap pin predates the
zipper fix; this is only the bounded adapter workload. It admits four exchanges,
with no silent history windowing. The existing model token budget may reject
sooner.

NARS recognizes two controlled-language inheritance premises forming one
three-symbol chain. It supports bounded plural forms, reversed order, separators,
multiword labels and explicitly hypothetical `Assume`/`Suppose` premises.
Unsupported prose remains ordinary conversation. This is a finite lexical
grammar: it rejects known qualifiers and `-ly` words but does not provide general
semantic hedge detection, morphology, or synonym resolution. Native
truth functions derive an uncertain belief; premise confidence is labeled
controller policy, not independent evidence. Committed observations survive
restart. Each v2 observation is keyed by the claimed session, request and CAS
revision; its evidence sidecar links native request/response and snapshot hashes.
A unique attempt suffix prevents directory collisions. ECAN's selected context
IDs remain separate from these observations.
All generated model prose is unverified. The endpoint has no action executor.

## Requalification

Use consumer-local runtime paths and a new profile filename. Run Python with
`-B` or `PYTHONDONTWRITEBYTECODE=1`: NARS checks complete source/runtime tree
membership, so newly generated bytecode inside a frozen tree invalidates it.
Do not rewrite old manifests to accommodate changed files.

`qualify_fresh.py` takes the original symbolic profile, native inference binary,
model and output arguments, plus:

- `--ecan-profile`: locally inventoried pinned ECAN fragment.
- `--nars-manifest`, `--nars-admission`, `--nars-evidence-root`: qualified local
  Hyperon/NARS closure, canonical digest and private evidence location.
- `--mork-manifest`, `--mork-manifest-sha256`: qualified local MORK closure.

Profile preparation verifies bytes; it is not a native conversation test.
`probe_integrated.py --profile ABSOLUTE_PROFILE --output NEW_DIRECTORY` performs
that test and saves raw diagnostics, internal synthetic state, native receipts,
and pass/fail assertions. The native model remains the pinned Granite GGUF;
no alternate hosted model or answer fallback is available.

The consumer MORK Cargo lock was newly resolved because the producer omitted its
lock. Its six original source pins were preserved; this does not claim
byte-identical producer dependency or binary reproduction. The optimized CPU
Granite build uses the same llama.cpp/source pins with explicit AVX2 flags and
AVX-512 disabled. The inference source disables extra weight buffers, keeping
weights mmap-backed under the original 6 GiB native address-space cap. Other
hosts must check CPU support and rebuild/requalify.

The inherited cognitive branch also carries MetaMo, NACE and AIRIS artifacts.
This conversation integration does not run those modules or establish new
qualification claims for them. It does not qualify a graphical bubble, guest
installation, arbitrary prose-to-logic extraction, full ECAN diffusion, or a
full autonomous Omega loop.

## Selected successor changes

The grammar and its tests were ported individually from published cognitive
commit `5367d32`, with additional conservative qualifier refusal cases. The
requested `f5ee004` was not available on the published branch during this port;
no claim of an exact diff or wholesale merge of that unpublished commit is made.
Pre-execution records, request-level native provenance and duplicate-ID admission
were implemented on the existing v2 integration. They preserve CAS and atomic
history/cognition commits.

The UTF-8 boundary regression uses a mocked native subprocess and real SQLite
commit/restart/replay. It forces an incomplete multibyte suffix. The separate
native Unicode probe reports whether the actual model chose such a suffix;
ordinary successful generation alone does not establish that reproduction. Raw
stdout bytes are retained as base64 with a byte count and SHA-256 before decoding.

The native Unicode probe did reproduce the boundary: one generated token emitted
bytes `f0 9f`, followed by the native newline (`0a`). V2 returned one U+FFFD plus
newline with `status: truncated`, kept the three-field generation metadata and
replayed the identical saved response without inference. Raw bytes remain in
the private receipt. Both expanded-language turns completed: “A red fox is an
animal” and “Robins are animals.” Their premise labels/modes remain provenance,
not a general factual-verification claim.

and continued the two-observation `language` session at revision 2. Native MORK

no new NARS inference or actions were performed. The original database remains
